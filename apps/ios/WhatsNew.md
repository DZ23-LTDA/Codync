## 2.19.2

### zh-Hant

- Bot 會用表情符號回應你的訊息，例如你道謝或分享好消息的時候。群組裡的 Bot 之間也會互相按表情。
- 記憶裡太長的內容會先收合成幾行，點一下就能看全文。
- 當機報告更完整，讓我們更快找到並修正 App 閃退的問題。

### en-US

- Bots react to your messages with emoji, like when you say thanks or share good news. In groups, bots react to each other too.
- Long memories fold to a few lines; tap one to read it all.
- More complete crash reports, so we can find and fix crashes faster.
