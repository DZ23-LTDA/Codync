## 2.19.2

### zh-Hant

- Bot 會用表情符號回應你的訊息：道謝時回一顆 ❤️，好消息回 🎉。群組裡的 Bot 之間也會互相按表情。
- 當機報告更完整，讓我們更快找到並修正 App 閃退的問題。

### en-US

- Bots react to your messages with emoji: a ❤️ when you say thanks, a 🎉 for good news. In groups, bots react to each other too.
- More complete crash reports, so we can find and fix crashes faster.
