# homebrew-codync

Homebrew tap for [Codync](https://github.com/DZ23-LTDA/Codync): message the coding agents on your computer as bots from iPhone, Mac, Linux or the terminal.

```sh
brew install --cask DZ23-LTDA/codync/codync    # Mac app (the host ships inside)
brew install DZ23-LTDA/codync/codync-host      # host only: Linux, headless Macs
```

Or without Homebrew: `curl -fsSL https://raw.githubusercontent.com/DZ23-LTDA/Codync/main/packaging/install.sh | sh`

Generated from [`packaging/homebrew`](https://github.com/DZ23-LTDA/Codync/tree/main/packaging/homebrew) by `tools/release-gate.py` in the Codync repo, for the release it marks latest; edit the templates there, not this repo.
